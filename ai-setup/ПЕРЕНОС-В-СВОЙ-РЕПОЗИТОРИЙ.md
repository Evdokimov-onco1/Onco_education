# Перенести эту папку в собственный репозиторий

Папка лежит внутри `Onco_education` временно: у сессии, которая её собрала, не было
права создавать репозитории на GitHub. Правильное место — отдельный репозиторий,
чтобы настройки не смешивались с проектом про ФОС.

Пять минут, делается один раз. После переноса этот файл удалить.

## 1. Создать пустой репозиторий

github.com → New repository → имя `ai-setup` → **Private** →
**не** ставить галочки «Add a README», «Add .gitignore», «Choose a license».

## 2. Перенести

Из папки, где лежит клон `Onco_education`:

```bash
cp -r Onco_education/ai-setup ~/ai-setup
cd ~/ai-setup
rm ПЕРЕНОС-В-СВОЙ-РЕПОЗИТОРИЙ.md

git init -b main
git add -A
git commit -m "Глобальная настройка Claude, Cursor и Devin"
git remote add origin git@github.com:Evdokimov-onco1/ai-setup.git
git push -u origin main
```

## 3. Установить

```bash
~/ai-setup/install.sh
```

Дальше — по `README.md`: вставить `rules.md` в Cursor User Rules и Devin Knowledge.

## 4. Убрать папку из Onco_education

```bash
cd Onco_education
git rm -r ai-setup
git commit -m "Вынести глобальную настройку в отдельный репозиторий"
git push
```

`AGENTS.md`, `CLAUDE.md` и `.ai/graph.md` при этом **остаются** в `Onco_education` —
это специфика проекта, ей там и место.
