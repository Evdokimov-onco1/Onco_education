# Восстановление на новой машине

Скиллы и плагины в этом репозитории **не хранятся** — они на аккаунте claude.ai
и приезжают сами при входе. Здесь только то, что живёт на машине.

## Скиллы — ничего не делать

Проверить, что синхронизация прошла:

```bash
ls ~/.claude/skills/synced/*/
```

Должны быть видны `evdokimov-deck`, `expert-review-kmp`, `otvet-na-zhaloby`,
`evdokimov-clinical-case` и остальные. Если пусто — запустить `claude` и `/login`.

Правятся скиллы на claude.ai → Settings → Capabilities → Skills.
После правки они сами разъезжаются по всем машинам и всем репозиториям.
Этот репозиторий для их обновления трогать не нужно.

## MCP-серверы

Ключ здесь — `--scope user`. Без него сервер привяжется к текущей папке
и в других проектах его не будет.

```bash
claude mcp add --scope user github -- npx -y @modelcontextprotocol/server-github
```

Проверить: `claude mcp list`

Записывать сюда каждый добавленный сервер, чтобы на новой машине не вспоминать.

| Сервер | Команда | Зачем |
|---|---|---|
| github | см. выше | PR, issues, Actions |

```
/plugin marketplace add <owner/repo>
/plugin install <name>@<marketplace>
```
