## Границы

- Персональные данные из `data/raw/` не покидают эту папку.
  Обезличивание — только скриптом, командой `/deident`.
- В отчёт идут цифры **из вывода скрипта**, не из ответа модели и не из
  прочитанного глазами. У каждой цифры в `out/` видно, чем она получена.
- Выводы о причинах не делаются из одних только этих данных: выгрузка
  показывает связь, а не причину.

## Чего не делать

- Не коммитить `data/raw/` — даже «на минутку, потом уберу».
  История git хранится вечно, удаление следующим коммитом не помогает.
- Не править результат руками в `out/`. Неправильная цифра чинится в скрипте.
