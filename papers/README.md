# Выкачка источников для вебинара по онкокардиологии при РПЖ

Инструмент забирает полные тексты из списка «Этап 2» легальными путями: Crossref → Unpaywall → Europe PMC. Без Sci-Hub и подобных зеркал — материал идёт на вебинар от лица клиники.

## Что здесь лежит

| Файл | Что это |
|---|---|
| `istochniki-etap2.md` | исходный список, как он был отобран из 8 обзоров UpToDate |
| `references.json` | тот же список в машинном виде — 77 записей (A: 34, B: 37, внешние: 6) |
| `fetch_papers.py` | сам конвейер |
| `requirements.txt` | одна зависимость — `requests` |
| `downloads/` | результат работы; в git не попадает |

## Запуск

```bash
cd papers
pip install -r requirements.txt

# сначала посмотреть, что вообще найдётся — ничего не качая
python3 fetch_papers.py --email evdokimov.onco@gmail.com --level A --dry-run

# скачать уровень А (34 источника)
python3 fetch_papers.py --email evdokimov.onco@gmail.com --level A

# уровни А и B
python3 fetch_papers.py --email evdokimov.onco@gmail.com --level AB

# отдельные позиции
python3 fetch_papers.py --email evdokimov.onco@gmail.com --only A4.1 A4.2 A5.1
```

Адрес почты обязателен — его требуют Crossref (за это пускают в «вежливый» пул с нормальными лимитами) и Unpaywall. Никуда, кроме этих двух API, он не уходит.

Прогон уровня А занимает 5–10 минут: между запросами стоит пауза в секунду, чтобы не долбить чужие сервисы.

Скрипт можно перезапускать сколько угодно — уже скачанные файлы пропускаются. Чтобы перекачать заново, добавьте `--force`.

## Что получается на выходе

```
downloads/
  pdf/
    A4-1_shore_2020_hero.pdf
    A4-2_lopes_2021_pronounce.pdf
    ...
  report.md       ← читать в первую очередь
  results.csv     ← та же таблица для Excel
  manifest.json   ← полные данные по каждой записи, включая перебранные ссылки
```

`report.md` состоит из трёх частей:

1. **Скачано** — что легло на диск, с OA-статусом и источником.
2. **Осталось добыть вручную** — с причиной и прямой ссылкой, куда идти. Порядок: институциональный доступ → сайт журнала → письмо corresponding author.
3. **Проверить сопоставление вручную** — если Crossref подобрал DOI с неполным совпадением названия. Обычно пусто.

## Как устроен конвейер

1. **Crossref** — по названию и авторам ищется DOI. Ответ не берётся на веру: кандидат проходит проверку на совпадение названия (с раскрытием сокращений вроде мКРРПЖ/ADT и с поправкой на то, что в исходном списке названия часто урезаны), плюс бонусы за совпадение года и журнала. Ниже порога 0.72 DOI не принимается — запись уходит в ручной список. Это дороже по покрытию, но исключает ситуацию, когда в папку тихо ложится не та статья: в списке есть близнецы вроде CARD (de Wit) и фазы II Annala с почти одинаковыми названиями.
2. **Unpaywall** — по DOI отдаёт легальную OA-копию, если она есть, и её статус (gold / green / hybrid / bronze / closed).
3. **Europe PMC** — добирает то, что депонировано в PMC. Здесь берутся работы, профинансированные NIH, — а их в списке много.
4. Каждая скачанная ссылка проверяется на то, что это действительно PDF, а не HTML-заглушка «требуется подписка». Файлы меньше 10 КБ отбраковываются.

## Чего ожидать по покрытию

Реалистично — от половины до двух третей уровня А.

Скорее всего возьмётся: заявления AHA/ACC, JACC CardioOncol, JAMA Netw Open, PLoS Med, Cochrane, рекомендации ESC 2022, Can Urol Assoc J.

Скорее всего не возьмётся, только абстракт: NEJM (HERO, ARASENS, VISION, EMBARK, CARD), Eur Urol, JCO, Lancet Oncol.

## Что скрипт не берёт принципиально

Записи `E2`–`E6` помечены `"manual": true` — это российские нормативные документы и один поисковый запрос:

- **E2, E3** — клинические рекомендации МЗ РФ: [рубрикатор](https://cr.minzdrav.gov.ru/)
- **E4, E5** — инструкции по применению энзалутамида и абиратерона: [ГРЛС](https://grls.rosminzdrav.ru/)
- **E6** — не статья, а поисковый запрос в PubMed на свежий метаанализ MACE для АРПИ 2 поколения

Их в Crossref нет, качаются руками с указанных порталов.

## Оговорка по списку

В шапке исходного файла указано «26 источников уровня B», фактически в тексте их 37. В `references.json` перенесены все 37 — ничего не отброшено.

Названия статей в `references.json` развёрнуты до полных журнальных заголовков (например, «mCRPC» → «metastatic castration-resistant prostate cancer»), иначе поиск в Crossref промахивается. Библиографические данные — журнал, год, том, страница — перенесены из исходного списка без изменений.
